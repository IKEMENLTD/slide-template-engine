# テンプレートの作り方（デザイナー向け手順書）

この手順書は、スライド自動生成エンジンが読む PowerPoint テンプレートの作り方です。
PowerPoint だけで作業でき、プログラムの知識は要りません。

エンジンは、原稿を読んで **ページごとに型（見本スライド）を選び、名前を付けた図形の中の文字と写真だけを差し替えます。**
色・位置・大きさ・字体・飾りの図形は、すべてテンプレートのとおりに残ります。テンプレートがデザインの正です。

---

## 1. 全体の考え方

- **1枚のスライド ＝ 1つの型。** エンジンは見本のスライドを複製して使います。スライドマスターやレイアウトには頼りません。
- **名前を付けた図形だけが差し替わります。** 名前の付け方は 4章。名前の無い図形・決まりに沿わない名前の図形は「飾り」として、そのまま残ります（エンジンは動かしません・消しません）。
- **文字は増えも減りもしません。** エンジンは字を小さくしない・枠を広げない・行を増やしません。欄に入らない文言は、言い換えて短くするか、別の型を選びます。だから **枠の大きさと字の大きさで、その欄に何字入るかが決まります。**
- **件数が違うものは別の型にします。** 課題が2件・3件・4件なら、3枚の見本を作ります（エンジンは図形を足したり消したりしません）。

## 2. 始める前に（テンプレート全体の設定）

| 項目 | 設定 | 理由 |
|---|---|---|
| スライドのサイズ | ワイド画面（16:9・13.333×7.5 インチ） | エンジンの基準 |
| 配色 | デザイン → バリエーション → 配色 → 色のカスタマイズ。**メインカラーをアクセント1、アクセントカラーをアクセント2** に入れる | 図形と文字は配色を参照させる（5章）。配色を替えるだけで全体の色が変わる |
| フォント | デザイン → バリエーション → フォント → フォントのカスタマイズ。見出し（日本語）＝大見出しの明朝、本文（日本語）＝ゴシック、英数字＝欧文 | 欄で「+見出し」「+本文」の字体を使うと、ここで一括で替えられる |
| 字体のファイル | 使う字体のファイル（.otf / .ttf）をエンジン担当に渡す（有償の字体は、ライセンスを確かめてから） | エンジンは実際の字体で文字の幅を測る |

**強調の色**：エンジンは、そのページで一番見てほしい語に、**太字＋アクセント2 の色の太い下線** を付けます。アクセント2 は「強調の色」として選んでください。

## 3. 型を1つ作る手順

1. 新しいスライド（白紙）を作り、見本のデザインを組む（図形・写真・文字）。
2. 文字の欄・数字の欄・写真の欄に名前を付ける（4章）。
3. 文字の欄の書式を決める（6章）。欄には「ダミー」と分かる見本の文字を入れる。
4. 写真の欄を作る（7章）。
5. ノート欄に型の情報を書く（8章）。
6. エンジン担当に渡して確かめる（10章）。

## 4. 図形の名前の付け方

名前は **選択ウィンドウ** で付けます（ホーム → 配置 → オブジェクトの選択と表示。または Alt+F10）。名前をダブルクリックすると書き換えられます。

| 名前の形 | 何の欄か | 例 |
|---|---|---|
| `txt.<欄名>` | 文言を入れる欄 | `txt.headline`、`txt.body` |
| `txt.<欄名>.<番号>` / `txt.<欄名>.<番号>.<部分>` | 繰り返しの欄 | `txt.item.1`、`txt.item.2.title` |
| `num.<欄名>` | 大きな数字だけを入れる欄（原稿にある数字だけが入る） | `num.value.1` |
| `img.<欄名>` | 写真を入れる欄 | `img.hero`、`img.item.1` |
| 上の形でない名前 | 飾り（触らない） | `deco.line`、`三角形 3` |

**よく使う欄の名前**（エンジンの AI は名前で欄の役割を知ります。新しい名前も使えますが、意味の分かる英語にしてください）

| 名前 | 役割 |
|---|---|
| `txt.headline` | そのページの見出し（大見出し） |
| `txt.subtitle` | 見出しを受ける副題 |
| `txt.eyebrow` | 見出しの脇の英字の小さなラベル |
| `txt.body` | 説明文 |
| `txt.point.N.lead` / `txt.point.N.main` | 要点N の小見出しと要点 |
| `txt.item.N`、`txt.item.N.title` / `.body` / `.caption` | 並べる項目N |
| `txt.label.N` / `num.value.N` / `txt.unit.N` / `txt.note.N` | 数値N のラベル・数字・単位・説明 |
| `txt.footnote` | 注記 |

決まり：

- **同じスライドに同じ名前を2つ付けない。**
- 繰り返しの番号は 1 から順に、抜けなく付ける。
- **欄はグループにしない**（飾りどうしのグループは可）。
- **プレースホルダー（「タイトルを入力」などの枠）を欄に使わない。** 挿入 → テキストボックス で作った枠を使う（書式をエンジンが読み取れるように）。

## 5. 色の付け方

- 図形の塗り・線・文字の色は、**配色（テーマの色）の中から選ぶ**。「その他の色」で色を直接指定しない。
  - 直接指定した色は、配色を替えても変わりません。エンジンは確かめるときに「色を直書きしている箇所がN個ある」と知らせます。
- メインカラーの濃淡は、配色の「アクセント1 の 明るさ/暗さ」の段（配色の下の行）を使う。
- 写真の上に色を重ねる表現（乗算）は、PowerPoint の図形ではできません。写真の色を重ねたい欄は、エンジン担当に「この写真の欄に、アクセント1 を乗算」と伝えてください（エンジンが写真に色を重ねてから差し込みます）。図形で近づけるなら、透明度を付けた図形を写真の上に置きます。

## 6. 文字の欄の書式

| 項目 | 設定 | どこで |
|---|---|---|
| 自動調整 | **自動調整なし** | 図形の書式設定 → 文字のオプション → テキストボックス |
| 行間 | **固定値**（例：字の大きさ 24pt なら 32pt） | 段落 → 行間 → 固定値 |
| 折り返し | 欄に応じて（1行で見せたい見出しは「図形内でテキストを折り返す」を外してもよい） | 同上 → テキストボックス |
| 余白 | 自由（エンジンは余白を引いた幅で測る） | 同上 |
| 書式 | **欄の最初の文字の書式が、入る文言すべてに使われる**（字体・大きさ・太さ・色・字間） | ホーム → フォント |
| 見本の文字 | 「ダミー見出し」のように **ダミーと分かる文字** を入れる。英字の欄なら「Dummy Label」 | — |

- **字体**：太さは字体の名前で選ぶ（例：中くらいの太さは「Noto Sans JP Medium」）。太字にしたいときは B ボタン。
- **字の大きさと枠の大きさは、実際の文言を入れて確かめる。** 欄に何字入るかは、エンジンが実際の字体で測って決めます（例：見出しの欄に最大 14 字×1 行）。
- ⚠️ **Illustrator の字幅で枠を決めない。** Illustrator はカナを詰めて組む設定（プロポーショナル）が既定ですが、PowerPoint は詰めません。同じ文言でも PowerPoint では **5〜14% 幅が広く** なります。枠は PowerPoint で文言を入れて決めてください。
- 見出しは2行まで（エンジンの設定）。それ以上は入りません。
- 記号は句読点・括弧・「・」「%」「/」程度に。「→」「①」「★」などは英数字の字体に無いことがあり、別の字体に置き換わります。

## 7. 写真の欄

1. 挿入 → 画像 で写真を入れる（見本の写真は何でもよい。エンジンが差し替えます）。**図形の塗りつぶし（図）は使わない。**
2. 図の形式 → トリミング → 図形に合わせてトリミング で形を選ぶ。平行四辺形・三角形・自由な多角形も使えます。
3. 選択ウィンドウで `img.<欄名>` と名前を付ける。
- 写真の縦横の比は、エンジンが枠に合わせて切り抜きます（人の顔などを残す位置で切ります）。写真はすべてモノクロにしてから入ります。
- 写真の中に文字を置かない（写真の上に文字を置くなら、文字の欄を別に作る）。

## 8. ノートに型の情報を書く

スライドのノート欄に、**次の形だけを書きます**（他のメモを書くと読めなくなります）。

```yaml
type: issues          # 型ID（英小文字・数字・ハイフン）
variant: "3"          # 件数違いなどの変種。無ければこの行は書かない
role: [problem]       # このページが向く役割（下の表から。複数なら [a, b]）
label: 課題提示（3項目）  # 人が読む名前
```

| role | どんなページか |
|---|---|
| `cover` | 表紙 |
| `toc` | 目次 |
| `section` | 中扉（章の区切り） |
| `problem` | 課題・悩みを並べる |
| `number` | 数字で見せる |
| `steps` | 手順・流れ・予定を並べる |
| `emphasis` | 重要なことを改めて言う |
| `photo-text` | 写真と文章で説明する |
| `closing` | 結び・問い合わせ先 |

新しい役割が要るときは、英小文字で名前を付けてエンジン担当に伝えてください。

- **型ID と変種の組み合わせは、テンプレートの中で重ならないようにする。**
- 件数違いは、同じ型ID に別の変種（`"2"`・`"3"`・`"4"`）を付けた別のスライドにする。
- 幅の広い変種（文字が多くても入る）を用意すると、エンジンは文字の多いページでそちらを選べます。

## 9. やってはいけないこと

- 文字の欄で「自動調整（はみ出す場合だけ自動調整する）」を使う → エンジンが止めます（字を小さくして収めるのはルール違反）。
- 欄の行間を「倍数」「1行」にする → 何行入るかが決まらず、推定になります（エンジンが注意を出します）。
- 色を「その他の色」で直接指定する → 配色の差し替えが効きません。
- 欄をグループにする・プレースホルダーを欄に使う。
- 同じスライドに同じ名前の欄を2つ作る。
- 見本の文字を、本番で使いそうな文言にする（エンジンは「見本の文字が残っている」と誤って止めます）。
- 有償の字体のファイルを、公開の場所（共有リンク・公開リポジトリ）に置く。

## 10. 確かめ方

エンジン担当が `slidegen catalog` を実行すると、型ごと・欄ごとに次の一覧ができ、問題があれば知らせます。

| 出てくるもの | 意味 |
|---|---|
| 欄ごとの「最大 N 字（1行 M 字×L 行）」 | その欄に入る文字数。少なすぎたら枠か字の大きさを見直す |
| 止める：ノートに type が無い／型が重複／欄の名前が重複 | 8章・4章を見直す |
| 止める：自動縮小が有効 | 6章（自動調整なし） |
| 止める：字体の実フォントが設定に無い | 字体のファイルをエンジン担当に渡す |
| 止める：見本の文言が欄に収まらない | 見本の文字が自分の欄に入っていない＝枠が小さすぎる |
| 注意：行間が固定値ではない | 6章（固定値） |
| 注意：色を直書きしている箇所がある | 5章 |
| 注意：設定 images に無い | 写真の欄の加工（モノクロ・乗算）をエンジン担当が設定する |

自分で確かめられること（チェックリスト）：

- [ ] 選択ウィンドウで、文字・数字・写真の欄に `txt.` `num.` `img.` の名前が付いている
- [ ] 文字の欄はすべて「自動調整なし」・行間「固定値」
- [ ] 見本の文字が「ダミー…」「Dummy…」になっている
- [ ] 色は配色の中から選んでいる
- [ ] ノートに type・role・label（件数違いは variant も）がある
- [ ] 実際の長さの文言を入れて、欄に収まることを PowerPoint で確かめた

## 11. 例：新しい型「引用」を1つ足す

お客様の声を1つ大きく見せる型を足す例です。

1. 白紙のスライドを足し、左に写真、右に大きな引用文、下に話した人の肩書きを置くデザインを組む。飾りに、アクセント2 の平行四辺形を1つ置く。
2. 写真：挿入 → 画像 → 図形に合わせてトリミング（平行四辺形）→ 名前 `img.photo`。
3. 引用文：テキストボックス → 名前 `txt.quote` → 明朝・28pt・行間 固定値 40pt・自動調整なし → 見本の文字「ダミーの引用文」。
4. 肩書き：テキストボックス → 名前 `txt.source` → ゴシック・14pt・行間 固定値 20pt・自動調整なし → 見本の文字「ダミー肩書き」。
5. 見出し：テキストボックス → 名前 `txt.headline` → 見出しの書式 → 見本の文字「ダミー見出し」。
6. ノートに書く：

   ```yaml
   type: quote
   role: [emphasis]
   label: 引用（お客様の声）
   ```

7. エンジン担当に渡す → `slidegen catalog` で「型 quote：txt.quote 最大 N 字…」と出て、止める問題が無いことを確かめる。

これで、エンジンは「重要なことを改めて言う」ページに、この型も選べるようになります。
